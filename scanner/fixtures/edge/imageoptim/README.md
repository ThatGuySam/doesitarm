# imageoptim

The XZ stream uses CRC64 and a 64 MiB LZMA2 dictionary. The local and remote CLI profiles now permit the observed dictionary size. Worker reports its decoder limit.

Version `1.9.3`. Original artifact 3,858,908 bytes. The fixture uses generated headers and stub bodies. [Pinned download](https://imageoptim.com/ImageOptim1.9.3.tar.xz)

Run `python3 fixtures/edge/check.py --cli target/release/scan-cli imageoptim` from the scanner directory.
