# fabfilter-timeless

A disk image contains a flat audio plug-in installer package. The fixture preserves the DMG, XAR and CPIO layers and the product bundle declared in PackageInfo.

Version `3.10`. Original artifact 22,061,225 bytes. Generated content contains synthetic Mach-O headers and stub bodies. [Pinned download](https://cdn-b.fabfilter.com/downloads/fftimeless310.dmg)

Run `python3 fixtures/edge/check.py --cli target/release/scan-cli fabfilter-timeless` from the scanner directory.
