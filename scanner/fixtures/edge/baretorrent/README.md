# baretorrent

The origin honored the discovery range with 206 and returned a whole-body HTTP 200 on a subsequent range. The fixture generator writes the original container type. The CLI test serves it with the observed range behavior over a loopback HTTP connection. The scanner restarts the parse from the whole response under the remaining budget.
