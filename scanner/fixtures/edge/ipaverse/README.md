# ipaverse

Version `2.5.3`. The 18,912,768-byte download starts with a protective MBR. The CLI formerly reported an unrecognized format because it expected a UDIF trailer. The fixture preserves the raw GPT and HFS+ container and the cask's `ipaverse.app` target.

[Pinned asset](https://github.com/bahattinkoc/ipaverse/releases/download/v2.5.3/ipaverse.dmg)

Run `python3 fixtures/edge/check.py --cli target/release/scan-cli ipaverse` from the scanner directory.
