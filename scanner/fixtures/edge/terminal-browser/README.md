# terminal-browser

The shell launcher computes ROOT from its own bin directory and names a compiled Electron app entry point. The fixture puts that app before the script to exercise bounded stream replay.

Version `0.16.1`. Original artifact 143,837,820 bytes. Generated content contains synthetic Mach-O headers and stub bodies. [Pinned download](https://terminal-browser.sh/install/dl/stable/v0.16.1/terminal-browser-darwin-arm64.tar.gz)

Run `python3 fixtures/edge/check.py --cli target/release/scan-cli terminal-browser` from the scanner directory.
