# fabfilter-pro-ds

A disk image contains a flat audio plug-in installer package. The fixture preserves the DMG, XAR and CPIO layers and the product bundle declared in PackageInfo.

Version `1.32`. Original artifact 16,911,289 bytes. Generated content contains synthetic Mach-O headers and stub bodies. [Pinned download](https://cdn-b.fabfilter.com/downloads/ffprods132.dmg)

Run `python3 fixtures/edge/check.py --cli target/release/scan-cli fabfilter-pro-ds` from the scanner directory.
