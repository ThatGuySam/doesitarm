How it works

The scanner reads executable headers and package metadata to identify processor architecture. It reads only the ranges it needs, even for large downloads. Local files never leave this browser.

Disk images, ZIP, PKG and tar.gz files are opened in place. Folders and .app bundles are checked by the executable named in their Info.plist.

Dropping a folder needs a browser that exposes folder contents to the page. If Firefox or another browser finds no files in a dropped folder, use Choose folder.

    What do the results mean?

    ✓ Apple Silicon native means the main executable has a verified arm64 or arm64e slice. Universal means it also has a verified 64-bit Intel slice.

    ◆ Intel only means only an x86_64 slice was found. The app may run through Rosetta 2 translation, usually slower and with more battery use.

    The binary inventory shows the slices observed in plug-ins, helper tools and other components.

    Why couldn't an app be checked?

    ? Unknown means the scanner stopped before it could verify an architecture: the file was damaged or unsupported, the browser could not read it, or a read limit was reached. Open the row's Details for the reason.

    If a scan never seems to end, try fewer apps at once or scan the app inside the disk image. For folders that drop empty, use Choose folder.

    How does Rosetta work?

    Rosetta 2 translates Intel apps so they can run on Apple silicon. Most Intel apps work, but this scanner cannot tell whether a specific app will run correctly under Rosetta. Apple has said Rosetta will be limited in future macOS releases, so native apps are the safer choice.
