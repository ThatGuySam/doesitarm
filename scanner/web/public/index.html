Scan help

The scanner reads executable headers and package metadata to identify processor architecture. It reads only the ranges it needs, even for large downloads. Local files never leave this browser.

Disk images, ZIP, PKG and tar.gz files are opened in place. Folders and .app bundles are checked by the executable named in their Info.plist.

If your browser cannot open a folder with Choose folder, drag the folder or individual .app bundles into the scanner.

✓ Apple Silicon native means the main executable has a verified arm64 or arm64e slice. Universal means it also has a verified 64-bit Intel slice. ◆ Intel only means only an x86_64 slice was found; the app may run through Rosetta 2, usually slower and with more battery use. Rosetta will be limited in future macOS releases, so native apps are the safer choice.

? Unknown means the scanner stopped before it could verify an architecture: the file was damaged or unsupported, the browser could not read it, or a read limit was reached. Open the row's Details for the reason. If a scan never seems to end, try fewer apps at once or scan the app inside the disk image.
