# Does It ARM plugin for Claude

Bundles the Does It ARM MCP server (https://mcp.doesitarm.com/mcp, the same URL as the Claude directory connector) with the `doesitarm-inventory` skill for checking Mac app inventories.

- Connector listing: https://claude.ai/directory/connectors/doesitarm
- Docs: https://github.com/ThatGuySam/doesitarm/blob/master/docs/mcp.md
- Privacy: https://doesitarm.com/privacy
