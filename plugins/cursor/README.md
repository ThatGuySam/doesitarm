# Does It ARM plugin for Cursor

Adds the Does It ARM MCP server (`https://mcp.doesitarm.com/mcp`, Streamable HTTP, no sign-in, read-only) and the `doesitarm-inventory` skill.

Ask things like "Does Blender run natively on Apple Silicon?" or "Check these apps for Apple Silicon support: Slack, Zoom, Docker". For Mac fleet inventories, the skill walks through exporting from your MDM and checking the list.

No configuration is needed. Docs: https://github.com/ThatGuySam/doesitarm/blob/master/docs/mcp.md · Privacy: https://doesitarm.com/privacy
